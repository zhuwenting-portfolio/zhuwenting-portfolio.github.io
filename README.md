## 页面说明

`index.html` 是独立 HTML 页面，内含样式与图标，无需安装依赖，可离线阅读。实习项目展示背景、职责和流程，展开后可查看实现细节、示意案例及相关实验记录；研究实践完整展示数据处理、模型设计与实验成果。支持手机和桌面布局。

流程图与示例用于解释方案；研究与评测指标仅对应页面说明的实验设置。页面不包含企业内部数据、接口地址或在线模型服务。
