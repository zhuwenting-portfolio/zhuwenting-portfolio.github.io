## 页面说明

`index.html` 为独立 HTML 页面，内含样式与图标，无需安装依赖；双击即可在浏览器中查看。实习项目详情使用原生折叠组件，研究实践完整展示数据处理、模型设计与实验成果；可离线阅读，支持手机和桌面布局。

流程图为技术方案示意；研究指标仅对应页面所说明的实验。页面不包含企业内部数据或在线模型服务。
